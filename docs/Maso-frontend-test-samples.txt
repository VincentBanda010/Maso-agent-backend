HOW TO RECORD RESULTS
----------------------
For each test, note:
- Sample number.
- Actual verdict.
- Whether AI completed.
- Whether OpenPhish completed, matched, failed, or was not applicable.
- Whether the result explained the evidence accurately.
- Time taken.

LIMITS OF THESE TESTS
---------------------
Model expectations above are test targets, not guaranteed predictions.
Record unexpected results as failures to investigate; do not change the
expected label just to match the output.

These samples test functionality, not overall model accuracy. Passing them
does not prove every requirement in the project document is complete.
Response time, concurrent capacity, privacy and independent detection accuracy
need separate testing. A missing feed entry is not a safety guarantee.
